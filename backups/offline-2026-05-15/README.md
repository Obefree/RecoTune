## Что внутри

| Файл / папка | Назначение |
|----------------|------------|
| `working-tree.patch` | Единый unified diff всех незакоммиченных изменений |
| `stat.txt` | Краткая статистика диффа |

## После `git pull` / слияния с актуальной main

1. Из корня репозитория попробовать:

   ```bash
   git apply backups/offline-2026-05-15/working-tree.patch
   ```

2. Если `git apply` ругается на контекст или CRLF:

   - Вручную перенести фрагменты из `working-tree.patch`, **или**
   - Сравнить / скопировать файлы из `files/` поверх актуальных путей:
     - `src/components/FrequencyChart.tsx`
     - `src/screens/ChordsScreen.tsx`
     - `src/screens/TunerScreen.tsx`

3. Проверить сборку: `npx tsc --noEmit`

## Важно

- Коммиты в историю Git этим бэкапом не делались — только файл-патч и снимки.
- Если после синхронизации в remote уже есть правки в тех же файлах, нужно будет **разрешить конфликты** или вручную перенести логику из `files/`.
