# Chords: практика — вёрстка, док, зона текста

**Дата:** 2026-05-15  
**Файлы:** `src/screens/ChordsScreen.tsx`

## Зачем

Больше места под текст с аккордами при открытой практике, предсказуемые высоты блоков, устранение «пустой полосы» между нижним доком (Мик/REC) и таб-баром из-за flex-вложенности.

## Док Мик / REC

| Было | Стало |
|------|--------|
| Бар дока внутри колонки практики (`practiceRootColumn`) | Бар вынесен **вниз корневого** `container` режима practice (абсолютное позиционирование относительно экрана Chords) |
| Подпись «Мик» в бейдже микрофона | **«MIC»** (латиница) |
| Кнопка «Мик» в доке | **«Mic»** |

Корневой `container`: добавлен **`position: 'relative'`** — якорь для абсолютного дока. У `practiceRootColumn` убран `position: 'relative'` (док больше не от него).

Колонка `mainScreenColumn` в режиме practice: **`paddingBottom: practiceDockHeight`**, чтобы контент не заезжал под док.

## Верхняя панель практики (гриф / график / ноты)

| Было | Стало |
|------|--------|
| Фиксированная высота встроенного графика `108/128` | При **наличии текста** (`hasLyricsBody`) график **ниже**: `44/56`; без текста — как раньше |
| Одна колонка без ограничения | Обёртка **`ScrollView`** с `maxHeight: practiceTopMaxH` при тексте, прокрутка только если есть текст |
| Строка диагностики всегда занимала место | Блок **`practiceDiagRow`** рендерится только если **`practiceDiagAny`** (включён гриф / график / ноты) |
| Диаграмма аккорда всегда `size="lg"` | С текстом песни — **`md`**, иначе **`lg`** |

Добавлены вычисления: `hasLyricsBody`, `practiceBodyApproxH`, `lyricsMinHeight` / `lyricsMinHeightRaw`, `practiceTopMaxH` (верхняя панель не больше ~30% тела при тексте и диагностике).

## Зона текста (аккорды + строки)

| Было | Стало |
|------|--------|
| `practiceLyricsStack` с `paddingBottom: practiceDockHeight` | **`minHeight: lyricsMinHeight`** при наличии текста; отступ снизу для дока перенесён на **`mainScreenColumn`** |

Типографика строк с аккордами (`ChordLyricsLine`): чуть крупнее шрифт/межстрочный интервал, отступы между блоками (`marginBottom` 10, аккорд 14/19, текст 16/24, цвет текста `#ddd`).
