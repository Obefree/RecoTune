# Тюнер: стабильность высоты тона и стрелки

**Дата:** 2026-05-15  
**Файлы:** `src/components/TunerEngine.tsx`, `src/screens/TunerScreen.tsx`, `src/components/TunerNeedle.tsx`

## Зачем

Меньше скачков частоты и дрожания стрелки при настройке «по стрелке»; более предсказуемое поведение на шуме и смене гармоники.

## TunerEngine (WebView, YIN)

| Было | Стало |
|------|--------|
| Первый лаг τ с `yin[tau] < 0.15` (ранний порог) | Поиск **глобального минимума** CMNDF по допустимым τ; отбраковка если `bestY > 0.18` |
| Сырая частота в `post('pitch')` | **Медиана** по кольцу из **7** последних частот + смягчение скачка относительно предыдущей стабильной (~±4 тона: смесь 0.55/0.45) |
| Порог RMS `0.008` | **`0.006`** (чуть чувствительнее к тихому сигналу) |
| Нет сброса состояния при тишине/нет pitch | Сброс `freqRing` и `lastStableF` при `signal` / тишине |

## TunerScreen (React Native)

| Было | Стало |
|------|--------|
| Один EMA `EMA_ALPHA = 0.28` по частоте | **`EMA_ALPHA_FREQ = 0.14`** по частоте |
| Центы напрямую из `frequencyToNote` | Дополнительный EMA по центам: **`EMA_ALPHA_CENTS = 0.22`**, внутреннее состояние float, наружу округление |
| Сброс только `smoothedFreqRef` на silent/signal | Сброс **`smoothedCentsRef`** там же |
| Старт/стоп не трогали refs | При **start** и **stop** сброс обоих smoothed-ref |

## TunerNeedle

| Параметр spring | Было | Стало |
|-----------------|------|--------|
| damping | 16 | **28** |
| stiffness | 110 | **52** |
| mass | 0.5 | **1.1** |
| overshootClamping | нет | **`true`** |

## Настройка «на слух»

Если стрелка станет слишком ленивой — поднять `EMA_ALPHA_FREQ` (например 0.18) или `EMA_ALPHA_CENTS` (~0.28). Если снова дёргается — можно увеличить `RING` в `TunerEngine` или чуть ужесточить порог `bestY`.
