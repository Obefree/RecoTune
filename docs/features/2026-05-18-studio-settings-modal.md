# Studio: модалки настроек / экспорта на маленьком экране

**Дата:** 2026-05-18  
**Файл:** `src/screens/StudioScreen.tsx`

## Проблема

При открытии настроек качества/латентности нижний таб-бар оставался поверх полупрозрачного оверлея, перехватывал нажатия; длинное меню не помещалось по высоте и не прокручивалось — «Закрыть» было недоступно.

## Что сделано

| Изменение | Зачем |
|-----------|--------|
| `useTabBarVisibility` — скрытие таб-бара, пока открыт любой из модалок Studio (настройки, экспорт, новая сессия, переименование) | Таб-бар не перекрывает и не блокирует модалку |
| `useFocusEffect` cleanup: сброс `tabBarHidden` и закрытие всех модалок при уходе со Studio | Не залипает скрытый таб и состояние |
| `Modal`: `statusBarTranslucent` (Android), `onRequestClose` | Системная кнопка «Назад» и полноэкранный слой |
| Оверлей: `Pressable` на весь экран под карточкой + тап по затемнению закрывает | Можно закрыть без кнопки |
| Модалки «Качество» и «Экспорт»: `ScrollView` с `maxHeight` от `useWindowDimensions` / safe area | Прокрутка на низких экранах |
| Экспорт: список дорожек через `.map` вместо `FlatList` внутри `ScrollView` | Избегаем конфликта вложенной прокрутки |

---

## Дополнение: live-тайминг при Play all

При воспроизведении всех дорожек изменение **offset** (±10 мс) раньше сохранялось в JSON, но **не** обновляло уже играющие `Audio.Sound`. Добавлена функция `liveResyncTrackOffsets(sess)`: читает текущую позицию опорной дорожки 0, вычисляет таймлайн сессии `T` и вызывает `setStatusAsync({ positionMillis })` для каждого звука по той же формуле, что и master seek. Вызывается из `updateTrackOffset` и `resetAllOffsets` после сохранения сессии.
