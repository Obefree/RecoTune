# Studio: компактный список сессий и модалка настроек

**Дата:** 2026-05-19  
**Файл:** `src/screens/StudioScreen.tsx`

## Проблема

После раскладки «сессии на весь экран» список проектов занимал слишком много места; модалка качества/звука (с блоком маршрутизации) не помещалась — кнопка «Закрыть» уезжала за край, прокрутка работала плохо.

## Что сделано

| Было | Стало |
|------|--------|
| Список SESSIONS `flex: 1` без проекта | Ограничение ~34% высоты экрана (макс. 280 px), прокрутка внутри |
| Компактный список при открытом проекте 128 px | ~72 px (1–2 строки) |
| Кнопка настроек только внутри проекта | Иконка ⚙ в шапке SESSIONS всегда |
| Панель Play/Rec/задержка под `FlatList` дорожек | В `ListFooterComponent` — прокручивается вместе с дорожками, не выталкивается |
| «Закрыть» внутри длинного `ScrollView` | Закреплена снизу карточки; контент модалки скроллится отдельно |
