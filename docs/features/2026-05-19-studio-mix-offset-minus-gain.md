# Studio: сведение с offset/VOL, минус с файла, громкость дорожек

**Дата:** 2026-05-19  
**Файл:** `src/screens/StudioScreen.tsx`

## Задача

1. При **Merge all → WAV** дорожки склеивались с нуля без учёта **offsetMs** (задержка/ручной тайминг), из‑за чего финал не совпадал с прослушиванием Play all / записью.
2. Нужна кнопка **«загрузить минус»** — поставить готовый бэк как **дорожку 1** (первая в сессии).
3. У каждой дорожки — **регулировка громкости** относительно остальных (в сведении и при Play all).

## Что сделано

| Было | Стало |
|------|--------|
| Web Audio mix: сумма семплов с начала каждого файла | В микшер передаются `offsets` (мс, как `offsetMs`) и `gains`; семпл `i` дорожки `b`: `fi = i + round(offsetMs*sr/1000)`; длина микса по крайней дорожке; затем `normArr` как раньше |
| Mute / volume в Play all только 0/1 | Учёт **`gain`** (0…2, в expo‑av воспроизведение до 1.0) + mute через `playbackVolume()` |
| Нет импорта бэка | Кнопка **«МИНУС»** + `expo-document-picker`: копия в `studio/`, пустая сессия → первая дорожка; если дорожки уже есть — диалог **заменить дорожку 1** (старый файл в `studio/` удаляется) |
| Нет поля громкости | В модели **`Track.gain`** (опционально), в строке дорожки **VOL ±5%**, сохранение в `studio_sessions.json` |

**Сведение:** в WAV попадают те же **mute**, что на момент нажатия Merge (через `mutedRef`): заглушённая дорожка даёт `gain 0` в WebView.
