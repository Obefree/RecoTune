# Тюнер: настройка по струне, не по «случайной» ноте

**Дата:** 2026-05-19  
**Файлы:** `src/screens/TunerScreen.tsx`, `src/utils/noteUtils.ts`, `src/components/FrequencyChart.tsx`, `src/components/MiniCentsStrip.tsx`, `src/components/TunerEngine.tsx`

## Проблема

Стрелка и график показывали центы до **ближайшей хроматической** ноты (A, A#, B…), из‑за чего при настройке, например, **3-й струны G** метка прыгала на соседние ноты. Не было явной цели на графике. Высокие частоты хуже ловились (потолок ~1400 Hz).

## Что сделано

| Было | Стало |
|------|--------|
| Крупно: название слышимой ноты | Крупно: **номер струны** + нота **строя** (G3…) |
| Центы до хроматической ноты | Центы до **ближайшей струны** выбранного инструмента/строя |
| «Слышимая» нота крупно | Мелко «слышится …», только если отличается от цели |
| Стрелка / мини-график по chromatic ¢ | По **stringCents** (±50¢ на мини-полосе) |
| График: цент плавает по среднему midi | В режиме нот: **фикс. линия цели** ⌖; в ¢ — метка струны |
| Подсветка струны только &lt;50¢ | Всегда ближайшая; **тап по пилюле** — зафиксировать струну |
| YIN до 1400 Hz | До **2000 Hz**, порог шума чуть мягче |

## Логика

`findNearestString` + `centsToStringTarget` (октава подбирается к открытой струне). Гистерезис ~28¢, чтобы не прыгать между соседними струнами.
