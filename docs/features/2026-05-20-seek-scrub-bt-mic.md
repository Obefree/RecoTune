# Перемотка без дёрганья + микрофон Bluetooth в настройках

**Дата:** 2026-05-20  
**Файлы:** `SeekBar.tsx`, `RecordingInputPicker.tsx`, `StudioScreen.tsx`, `RecorderScreen.tsx`, `PlayerScreen.tsx`, `studioAudioRouting.ts`

## 1. Перемотка при воспроизведении

| Было | Стало |
|------|--------|
| Seek на каждом движении пальца | Ползунок двигается локально; **seek один раз при отпускании** |
| Позиция сбивалась с `onPlaybackStatusUpdate` | Во время scrub обновления UI из статуса **блокируются** |
| Play all / solo дергались при scrub | На время перетаскивания — **пауза**, после отпускания — seek и **продолжение** |

Затронуто: Studio (Play all, solo дорожка), Recorder (прослушивание записи), Player.

## 2. Микрофон Bluetooth (гарнитура)

| Было | Стало |
|------|--------|
| BT-мик только в Studio → ВРУЧНУЮ → внизу списка | Блок **«Микрофон записи»** в настройках Recorder и Studio (всегда виден) |
| Recorder без выбора входа | Тот же `studio_audio_routing.json` + `applyRecordingInput` при записи |

Подключи гарнитуру → ⚙ → обновить список → выбери **Bluetooth**.
