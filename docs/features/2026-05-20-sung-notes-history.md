# История спетых нот (тюнер + практика)

## Зачем

При напеве мелодии («pom pam pam») пользователь видит, какие **сильные** ноты реально распознаны — хроматически, без привязки к струнам. Staff/tab — позже; сейчас горизонтальная лента чипов.

## Было → стало

| | Было | Стало |
|---|------|-------|
| Язык по умолчанию | RU | EN (если нет сохранённого `app_locale.json`) |
| Тюнер при напеве | Только текущая нота | + лента распознанных нот с onset-фильтром |
| Практика Chords | Голос + график | + та же лента при Mic ON |
| Фильтрация | — | min signal, ~200 ms стабильности, spread центов ≤28, скачки >4 полутонов игнорируются без sustain ~220 ms, debounce ~380 ms на повтор |

## Как работает фильтр

1. **Сигнал** ниже порога → пауза, сброс «удержанной» ноты.
2. **Стабильность** ~200 ms при разбросе центов ≤ ~28 → регистрация одной ноты через `frequencyToNote`.
3. **Скачок >4 полутонов** — шум, пока новый pitch не держится ~220 ms.
4. **Debounce** — та же MIDI-нота не дублируется чаще ~380 ms; после регистрации та же нота не повторяется, пока не сменится pitch или не пропадёт сигнал.
5. **STOP / выкл Mic** — лента очищается.
