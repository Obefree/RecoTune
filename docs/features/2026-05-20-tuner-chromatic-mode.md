# Тюнер: хроматический режим по умолчанию

## Зачем

Обратная связь: тюнер ошибочно показывал «струна 1» для нот, которые не на первой струне; график при этом выглядел нормально. Для пения/скрипки/универсального использования нужны **нота + центы до ближайшего полутона**, без привязки к грифу гитары.

## Файлы

- `src/screens/TunerScreen.tsx` — основной UX
- `src/components/FrequencyChart.tsx` — график (chromatic cents по умолчанию)
- `src/components/MiniCentsStrip.tsx` — мини-полоса под стрелкой
- `src/i18n/strings.ts` — `noteLabel`
- `src/utils/noteUtils.ts` — комментарий: string-функции для будущего instrument mode

## Было → стало

| Было | Стало |
|------|-------|
| Верхняя полоса: **СТРУНА** + номер + целевая нота струны | **НОТА** + имя (G3, A4…) |
| Центы относительно ближайшей струны (`stringCents`) | Хроматические центы до полутона (±50¢) |
| Стрелка и мини-график по `findNearestString` | Стрелка и мини-график по `frequencyToNote` cents |
| График с `tuningTarget` от ближайшей струны | График без string target; центрирование по midi |
| Сетка пилюль струн внизу с lock/hysteresis | Убрана; picker инструмента/строя оставлен для будущего |
| Ложное «стр. 1» на высоких/соседних нотах | Нет string UI — проблема не проявляется |

## Как пользоваться

1. **START** — играйте/пойте любую ноту.
2. Смотрите **ноту** (слева), **центы** (центр), **Hz** (справа).
3. Стрелка и мини-полоса: отклонение от ближайшего полутона; 0¢ = в строю.
4. Переключатель **СТРЕЛКА / ГРАФИК** — режим ¢ или ноты по времени.
5. Кнопка инструмента вверху — выбор строя (пока не влияет на основной дисплей; для будущего string mode).
