# Тюнер: стабильная вёрстка, высокие ноты, RU/EN

**Дата:** 2026-05-20  
**Файлы:** `TunerScreen.tsx`, `FrequencyChart.tsx`, `TunerEngine.tsx`, `noteUtils.ts`, `src/i18n/*`, `LocaleContext.tsx`, `App.tsx`

## 1. Дёргание окна (ноты / график)

| Было | Стало |
|------|--------|
| `mainCard` без фикс. высоты | `minHeight` = max(стрелка+полоса, блок графика) |
| Строка «слышится …» появлялась и сдвигала блок | Слот `heardNoteSlot` с `minHeight` всегда |
| Центр графика в режиме нот плавал по среднему midi | EMA центра, при цели строя — фикс. `targetMidi` |
| Блок графика менял высоту | `TUNER_CHART_BLOCK_MIN_H` на контейнере |

## 2. Высокие ноты

| Было | Стало |
|------|--------|
| Гистерезис 28¢ | `hysteresisMarginCents`: 28 / 36 / 42¢ по частоте |
| Один EMA 0.14 / 0.22 | Выше 280 Hz: 0.09 / 0.15 |
| Только медиана + скачок ±4 тона | `foldHarmonics` (×2…×4, ÷2…÷4); на f≥320 скачок ~±2 тона |

## 3. Язык

- Переключатель **RU | EN** в шапке тюнера (сохранение в `app_locale.json`).
- Строки тюнера и графика через `useLocale()` / `strings.ts`.
- Остальные вкладки — по мере необходимости в те же словари.

## 4. Подсветка струн (пилюли) — не залипать на E2

| Было | Стало |
|------|--------|
| Октава ±2 → E2 «ловил» G3/B3/E4 | Октава только **±1**, не дальше 9 полутонов от строя |
| Авто-`lock` на каждом кадре → залипание 6-й | Lock **только** после тапа по пилюле |
| Пилюли = тот же lock, что стрелка | Пилюли = **живой** `findNearestString`; стрелка — гистерезис только при ручном lock |
| — | Сброс lock, если играешь другую струну (&lt;45¢ до неё) |
