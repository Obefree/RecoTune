# График: скролл к началу, разнесение меток

## Зачем

На вкладке **Мелодия** (и в тюнере) при многих точках истории метки зафиксированных нот слипались в одну колонку, скролл к началу истории был затруднён, а автоскролл к концу мешал просмотру начала.

## Файлы

- `src/components/FrequencyChart.tsx` — layout оси времени, stagger меток, stable pitch center, кнопка «⟵ Начало», `followEndRef`
- `src/components/MelodyPitchChart.tsx` — `defaultHZoom={2}`
- `src/i18n/strings.ts` — `chartScrollToStart`

## Было → стало

| Было | Стало |
|------|-------|
| X только по индексу точки, min cell не учитывался | При «скученных» ts — index layout + `MIN_CELL_W`; иначе пропорционально времени |
| Несколько меток на одном индексе — наложение | Stagger +16 px; ширина графика расширяется под overlap |
| `centerMidi` плавал (EMA) — метки по вертикали сжимались | Медиана последних 20 точек для Y меток |
| Melody: hZoom 1×, история слева | Стартовый zoom 2× |
| Автоскролл при `nearEnd` по `prev` | `followEndRef` — не тянет к концу, если пользователь листал назад |
| Нельзя быстро к началу | Чип **⟵ Начало** / **⟵ Start** сбрасывает `hScroll` в 0 |
| `maxScroll` от `(n-1)*cellW` без меток | `totalW` учитывает число меток и stagger при cluster |

## Как пользоваться

1. **Мелодия** — напевайте; метки разнесены по горизонтали, подписи не перекрываются.
2. **Свайп влево** — в начало истории; автоскролл к концу только если вы уже у правого края.
3. **⟵ Начало** — мгновенный jump к первым точкам.
4. **Щипок** — масштаб по времени (как раньше).
