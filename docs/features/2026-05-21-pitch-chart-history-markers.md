# График высоты: история, скролл, метки стабильных нот

## Зачем

На вкладках **Тюнер** (режим ГРАФИК) и **Мелодия** нужно видеть не только последнюю точку, а **весь след** по времени, листать назад и отмечать **устойчивые** ноты из `SungNoteDetector`.

## Файлы

- `src/components/FrequencyChart.tsx` — pan/pinch по времени, точки/линия, метки с подписью (E4…)
- `src/components/MelodyPitchChart.tsx` — подсказки скролла и меток
- `src/screens/TunerScreen.tsx` — `SungNoteDetector` + `registeredEvents` → график
- `src/screens/MelodyScreen.tsx` — без изменений (уже `useSungNoteHistory`)
- `src/i18n/strings.ts` — `chartScrollHistoryHint`, `chartStableMarkersHint`

## Было → стало

| Было | Стало |
|------|-------|
| Тюнер-график без детектора стабильных нот | Те же метки, что в Мелодии (режим «НОТЫ») |
| Метки — точка + вертикаль без текста | Чип с именем ноты (`E4`) у каждой зафиксированной ноты |
| Подсказка жестов без «истории» | Явно: свайп = листать историю |
| Автоскролл всегда к концу | К концу только если пользователь уже у правого края |

## Как пользоваться

1. **Тюнер → ГРАФИК** или **Мелодия** — START, пойте/играйте.
2. Режим **НОТЫ** (♩) — фиолетовые метки с подписью на устойчивых нотах.
3. **Свайп влево** — прошлые точки; **щипок** — масштаб по времени.
4. В **ЦЕНТЫ** (¢) — след отклонения; метки стабильных нот только в режиме нот.
