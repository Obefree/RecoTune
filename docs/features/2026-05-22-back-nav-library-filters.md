# Android Back + упрощение «База песен»

**Дата:** 2026-05-22  
**Зачем:** системная кнопка «Назад» должна закрывать оверлеи Chords, а не всегда уводить на Tuner; фильтры библиотеки занимали место без пользы.

## Файлы

| Путь | Изменение |
|------|-----------|
| `App.tsx` | `backBehavior="history"` у bottom tabs |
| `src/screens/ChordsScreen.tsx` | `BackHandler` stack на Chords; одна строка фильтров в модале |

## Было → стало

| Было | Стало |
|------|--------|
| Back на Android часто → вкладка Tuner | Сначала: модалы → правка текста → песня → НАЙТИ/LIVE → предыдущая вкладка по history |
| Жанры, сложность, 3 сортировки | Поиск + ⭐ Избранное + А→Я + счётчик |
| `searchSongsSmart` / rank при запросе | Без изменений (сортировка по rank при непустом поиске) |

## Стек Back (Chords, сверху вниз)

1. Добавить/редактировать песню, настройки провайдеров, справочники аккордов/инструментов  
2. Модал «База песен»  
3. Режим правки текста  
4. Immersive lyrics / скрытая панель практики  
5. Сброс выбранной песни в Практике  
6. НАЙТИ: запись → результат → под-вкладка → выход в Практику  
7. LIVE: останов → Практика  

## Проверка

1. Chords → База → Back — модал закрывается, остаётесь на Chords.  
2. Практика с песней → Back — сброс песни; ещё Back — без прыжка на Tuner (если до Chords был другой таб — туда).  
3. НАЙТИ с результатом → Back — очистка; ещё Back — Практика.  
4. База: только избранное и А→Я; поиск «кино» — порядок как раньше (smart rank).
