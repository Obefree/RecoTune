# Каталог: качество аккордов и текстов

**Дата:** 2026-05-22  
**Зачем:** ~536 песен в SQLite выглядели как «только название» — в UI была короткая прогрессия (C G Am F), без ChordPro-строк; поиск не поднимал полный текст; старые установки не получали обновление builtin из бандла.

## Файлы

| Путь | Изменение |
|------|-----------|
| `src/utils/songContent.ts` | Бейджи контента, `resolveSongEntry`, ранжирование |
| `src/db/songLibrary.ts` | Миграция `builtin_seed_version`, upsert builtin без затрагивания user |
| `src/db/searchSongsSmart.ts` | Песни с ChordPro-строками выше в выдаче |
| `src/providers/registry.ts` | Без подстановки `C G Am F` для lyrics-only |
| `src/screens/ChordsScreen.tsx` | `getSongById` при открытии, подсказки, бейджи в списке |

## Было → стало

| Было | Стало |
|------|--------|
| 536 записей: ~87 inline + ~69 в `LYRICS_DB` с полными строками; остальные — только прогрессия | Явные бейджи: **аккорды ✓** / **прогрессия** / **только название** |
| `seedBuiltinIfEmpty` — обновление каталога только на пустой БД | `upgradeBuiltinCatalog` при смене `BUILTIN_SEED_VERSION` (user-строки не трогаем) |
| `pickSong` без `LYRICS_DB` и без перечитывания SQLite | `loadSongForPractice` → `getSongById` + merge lyrics |
| Remote lyrics → фейковые аккорды `C G Am F` | Пустые аккорды + текст online + подсказка ChordPro |
| Пустой список без пояснения | Подсказка импорта ChordPro для «прогрессия» |

## Цифры (бандл)

- **536** песен в `songDatabase.ts` (все с полем `chords` — прогрессия).
- **~150** с полным ChordPro-текстом (inline + `lyricsDatabase.ts`).
- **~386** — metadata-only (прогрессия для практики-полоски, без строк `[Am]слово`).

## Проверка

1. Переустановка или обновление приложения → в логах/SQLite meta `builtin_seed_version` = `2026-05-22`.
2. **База песен** → «Let It Be» → бейдж **аккорды ✓** → в практике многострочный текст с `[C]`, `[G]`, …
3. Песня только с прогрессией → бейдж **прогрессия** → полоска аккордов + подсказка ChordPro.
4. НАЙТИ → Каталог → тот же бейдж и полное открытие из SQLite.

## Ограничения

- Массовое наполнение всех 536 ChordPro-строками в бандле не делалось (legal/объём); качество растёт через импорт и URL.
- lyrics.ovh даёт текст без аккордов в строках.
