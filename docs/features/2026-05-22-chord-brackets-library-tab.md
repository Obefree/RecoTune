# Chords: ложные скобки в тексте + база при входе на вкладку

**Дата:** 2026-05-22

## Зачем

- В практике в словах появлялись `[a]`, `[e]` (статьи, слоги) — особенно после merge строки аккордов над текстом (Creep и др.).
- При нажатии «Аккорды» в нижней навигации пользователь должен сразу видеть **База песен**, а не прошлую практику.

## Файлы

| Файл | Изменения |
|------|-----------|
| `src/utils/chordLyricsNormalize.ts` | `stripSpuriousChordBrackets`, строже `isBareWordChordToken`, merge только при совпадении числа аккордов/слов |
| `tools/verify-chord-normalize.mjs` | тесты Creep / feather / chorus |
| `src/screens/ChordsScreen.tsx` | `useFocusEffect` → `setShowLibrary(true)`; пустая практика по умолчанию |

## Было → стало

| Было | Стало |
|------|--------|
| `a`, `A`, `I` как «аккорды» в prose | Не оборачиваются; `[a]` снимается при загрузке |
| `G` над строкой → `[G]` на каждое слово | Один аккорд → префикс строки `[G]Couldn't…` |
| 4 аккорда / 5 слов → `[Cm]a` | Merge пропускается, строки раздельно |
| Вкладка Аккорды → практика с дефолтом Am F C G | Модал «База песен» при каждом фокусе вкладки |
| Пустой экран: общая подсказка | Без песни: «Выберите песню из базы…» |

## Проверка

1. `npm run verify-chord-normalize`
2. Аккорды → сразу модал базы; закрыть без выбора → пустая практика.
3. Creep / подгруженный таб: нет `[a]` в «feather», «I'm a creep».
