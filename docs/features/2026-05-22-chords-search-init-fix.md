# Chords: починка поиска в каталоге и НАЙТИ

**Дата:** 2026-05-22  
**Зачем:** поиск в «База песен» и на вкладке НАЙТИ → Каталог возвращал пусто из‑за гонки с инициализацией SQLite.

## Файлы

| Путь | Изменение |
|------|-----------|
| `src/db/songLibrary.ts` | `listSongs` и др. ждут `initSongLibrary`; повтор init при сбое |
| `src/providers/registry.ts` | `searchProviders` ждёт init; `searchResultToSongEntry` |
| `src/screens/ChordsScreen.tsx` | debounce каталога НАЙТИ; пустые состояния; подсказки UX |

## Было → стало

| Было | Стало |
|------|--------|
| `searchProviders` до готовности БД → throw, catch → `[]` | Init перед каждым запросом к SQLite |
| Выключен провайдер «Каталог» → умный поиск без builtin | Офлайн SQLite всегда в поиске; тумблеры только remote/on-demand |
| `build: chord-v2` только в `__DEV__` | Маркер всегда в шапке Chords + seed в подзаголовке «База песен» |
| НАЙТИ Каталог — только по кнопке | Поиск с debounce при вводе (как в «База песен») |
| Remote hits без `song` отбрасывались | `searchResultToSongEntry` для lyrics/ChordPro |
| «Вручную» выглядело как каталог | Подпись: текст online, каталог — вкладка «Каталог» |

## Где искать песню

1. **Практика → «База песен»** — умный офлайн-поиск по всей библиотеке.
2. **Chords → НАЙТИ → Каталог** — тот же поиск (не путать с «Вручную» / «НАЙТИ ТЕКСТ»).
