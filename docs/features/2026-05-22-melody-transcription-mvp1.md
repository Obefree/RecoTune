# Melody transcription MVP 1 (контур по кадрам)

## Зачем

График высоты уже показывает спетую линию, но `SungNoteDetector` регистрировал ноты по устойчивому кандидату — число нот и PLAY не совпадали с тем, что видно на графике.

## Файлы

| Файл | Изменение |
|------|-----------|
| `src/utils/pitchFrame.ts` | Тип `PitchFrame`, кольцо ~12 с |
| `src/utils/melodyTranscription.ts` | `transcribeFromPitchFrames`, сегменты по контуру |
| `src/hooks/useSungNoteHistory.ts` | Кольцо кадров, детектор `repeatGapMs` 130 / `minStableMs` 100 |
| `src/utils/melodyPlayback.ts` | `buildMelodyPlaybackPayloadFromSegments` — PLAY по start/end сегмента |
| `src/screens/MelodyScreen.tsx` | EMA 0.12, сырой pitch в кадры, переключатель контур/классика, счётчики |

## Было → стало

| Область | Было | Стало |
|---------|------|--------|
| Источник нот | Только onset-детектор | Параллельно: кадры → контур; детектор для сравнения |
| PLAY | Интервалы между `registeredEvents.ts` | При «контур» и уверенности — длительность сегмента с графика |
| Сглаживание Melody | EMA 0.18 | 0.12; в кадры — сырой `frequency` |
| UX | Только dev YIN chip | Переключатель «контур / классика», строка кадры/ноты |

## Ограничения (MVP)

- Повторы одной высоты без паузы >150 ms могут сливаться в одну ноту.
- Нет onset по энергии — только контур + тишина.
- Квантование в тональность по-прежнему от списка нот активного режима.
- Сохранённые мелодии без `pitchFrames` — только классика после загрузки.

## Проверка

1. Melody → START, медленная гамма (до–ре–ми…), паузы между звуками.
2. Смотреть «кадры N · ноты M / классика K» — M ближе к числу «горбов» на графике.
3. PLAY с переключателем «контур» — ритм ближе к паузам на графике; «классика» — старое поведение.
4. Тюнер — без регрессий (общий `TunerEngine`).
