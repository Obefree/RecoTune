# Pitch graph smoothing regression fix

## Зачем

После Melody MVP1 графики высоты стали «лесенкой» в тюнере, Melody и воспринимались как сломанные: неверные ноты, странный ритм, дёрганая линия.

## Причина

1. **Общий `TunerEngine`** — в MVP1 расширили диапазон YIN (55–2000 Hz), добавили `foldHarmonics` и ужесточили подавление скачков на высоких нотах (ratio 1.14). Это затронуло **все** экраны с `TunerEngine` (тюнер + Melody).
2. **Melody MVP1** — EMA 0.12 для UI и **сырой** pitch в `pitchHistory` / кадры → график рисовался без сглаживания, хотя детектор и контур получали шумные точки.
3. **`useSungNoteHistory`** — агрессивные `repeatGapMs: 130` / `minStableMs: 100` ускоряли классический детектор и давали лишние/ранние ноты.

Chords Практика использует **отдельный** chord WebView (HPS + EMA 0.28) — не затронут правками `TunerEngine`.

## Файлы

| Файл | Изменение |
|------|-----------|
| `src/components/TunerEngine.tsx` | Откат melody-специфики: диапазон 60–1400 Hz, медиана без `foldHarmonics`, порог YIN 0.18 |
| `src/screens/TunerScreen.tsx` | EMA частоты/центов ~0.20–0.22 (низкие ноты), 0.16–0.20 (высокие) |
| `src/screens/MelodyScreen.tsx` | DISPLAY_EMA 0.20; сырой pitch → детектор/кадры, сглаженный → график |
| `src/hooks/useSungNoteHistory.ts` | `chartFrequency` для истории; детектор с дефолтными порогами |

## Было → стало

| Область | Было (регрессия) | Стало |
|---------|------------------|--------|
| TunerEngine | foldHarmonics, 55–2000 Hz, жёсткий ratio на высоких | Стабильная медиана 7 кадров, 60–1400 Hz |
| Melody график | Сырой pitch в `pitchHistory` | Сглаженный `chartFrequency`, сырой — только в кадры/детектор |
| Melody UI EMA | 0.12 | 0.20 |
| Melody детектор (классика) | repeatGap 130 / minStable 100 | Дефолты `SungNoteDetector` |
| Тюнер EMA | 0.14 / 0.09 freq | 0.20 / 0.16 freq |

## Проверка

1. **Тюнер** — одна струна, стрелка и график без скачков октав; центы плавные.
2. **Melody** — START, медленная гамма: линия графика гладкая, не ступеньки; метки нот ближе к устойчивым звукам.
3. **Melody контур** — переключатель «контур»: кадры по-прежнему с сырого pitch (onset виден), PLAY не регрессирует.
4. **Chords Практика** — голосовой график без изменений (отдельный движок).
