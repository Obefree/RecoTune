# Chords: поиск в Практике (база песен)

**Дата:** 2026-05-22  
**Зачем:** удобный поиск аккордов — в модалке «База» на вкладке ПРАКТИКА (старый простой UI), а не дублирующий каталог на НАЙТИ.

## Файлы

- `src/screens/ChordsScreen.tsx`

**2026-05-22 (layout):** шапка модалки в ряд (`flexDirection: 'row'`), `FlatList` с `flex: 1` — поиск + результаты ~70%+ высоты, без чёрной пустоты снизу. См. [2026-05-22-practice-library-modal-layout.md](./2026-05-22-practice-library-modal-layout.md).

## Было → стало

| Было | Стало |
|------|--------|
| Стартовая вкладка НАЙТИ | По умолчанию ПРАКТИКА |
| НАЙТИ→Каталог: отдельный поиск, pills, прогресс | Кнопка «Открыть базу в Практике» → та же модалка |
| База: subtitle индекса, progress, бейджи провайдеров | Короткий заголовок, список как раньше |
| Поиск metadata только в НАЙТИ | `searchProviders` в модалке База (debounce без смены UI) |
| `chord-v3` / build в модалке | Не показываем |

## Проверка

1. Аккорды → открывается ПРАКТИКА.
2. «База песен» → поиск, фильтры, выбор песни.
3. НАЙТИ → Каталог → переход в базу Практики.
