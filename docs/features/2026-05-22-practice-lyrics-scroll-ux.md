# Практика: прокрутка текста и автопрокрутка

**Дата:** 2026-05-22  
**Файл:** `src/screens/ChordsScreen.tsx`

## Зачем

Ручная прокрутка текста в Практике конфликтовала с вложенным `ScrollView` панели сверху; кнопки автопрокрутки были слишком мелкими, BPM ± вложены в один `TouchableOpacity` (ломали тапы).

## Было → стало

| Область | Было | Стало |
|--------|------|--------|
| Вложенный скролл | При загруженном тексте скроллилась и верхняя панель, и колонка текста | Верхняя панель не скроллится при тексте (`scrollEnabled={!hasLyricsBody}`); скролл только у текста |
| Ручной скролл vs авто | Интервал `scrollTo` без остановки при жесте | `onScrollBeginDrag` / `onMomentumScrollBegin` → `stopAutoScroll()` |
| Кнопки | Play+BPM+± в одной кнопке ~9px, иконка 11 | Отдельная строка: play/pause 44×44, BPM ±10 по 44×44, значение BPM по центру |
| BPM при авто | `stopAutoScroll` сбрасывал UI, `startAutoScroll` не включал снова | `startAutoScroll` выставляет `autoScroll: true`; при ± перезапуск по `autoScrollIntervalRef` |
| Очистка | Интервал мог остаться при смене режима | `useEffect` cleanup + стоп при уходе из practice / edit |

Семантика BPM: шаг ±10, диапазон 30–240 — без изменений.
