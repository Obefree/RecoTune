# Практика: тихая подгрузка аккордов и ⚙ в шапке

## Зачем

Пользователь видел «Нет источников» и не находил настройки прокси/AmDm. Нужна автоматическая подгрузка без Alert и явная кнопка ⚙ на экране Практика.

## Файлы

- `src/screens/ChordsScreen.tsx` — шапка Практика, `pickSong`, `enrichSongForPractice`, модал источников
- `src/utils/songContent.ts` — мягкий текст прогрессии
- `src/providers/providerSettings.ts` — флаг `devProxyUrlHintDismissed`

## Было → стало

| Было | Стало |
|------|--------|
| После выбора песни с прогрессией — Alert «Нет источников» / выбор источника | Цепочка без диалогов: каталог → lyrics.ovh → AmDm (если прокси+включён) |
| ⚙ только в модале «База песен» | ⚙ в шапке Практика (рядом с «База песен») + в базе |
| Ошибка прокси — Alert с инструкцией | Одна строка под полосой аккордов; в `__DEV__` — `console.warn` |
| «Загрузить аккорды» сразу | Кнопка после завершения тихой попытки, если таба всё ещё нет |
| Модал источников — чёрный блок, контент без скролла | `ScrollView` + `flex: 1` |
