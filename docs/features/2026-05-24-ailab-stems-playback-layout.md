# AI Lab: дорожки — вокал, минус, воспроизведение

**Зачем:** вкладка «ДОРОЖКИ» в AI Lab — явный выбор вокала/минуса, больше рабочей зоны, рабочее ▶ после разделения.

## Файлы

| Файл | Изменения |
|------|-----------|
| `src/screens/AILabScreen.tsx` | Режимы `vocals` / `minus` / `all`, WebView `separate(b64, mode)`, UI, playback |

## Было → стало

| Тема | Было | Стало |
|------|------|--------|
| Режим вывода | Всегда 5 дорожек | Чипы **ВОКАЛ** / **МИНУС** / **ВСЕ 5** до выбора файла |
| Вокал | «Голос» среди пяти | Режим «только вокал»; метка **Вокал** |
| Минус | Среди пяти | Режим «только минус» (инструментал/караоке) |
| Layout | `ScrollView`, много пустого низа | `flex:1` + `FlatList` дорожек, крупнее полоса прогресса |
| Playback | `createAsync` без `file://`, ошибки глотались | `applyPlaybackAudioMode`, `assertPlaybackFileExists`, `toggleStem` по `getStatusAsync` |
| Имена файлов | Кириллица в пути | `stem_vocals_*.wav`, `stem_minus_*.wav` |

## Ограничения

Офлайн-алгоритм (полосы + центральный канал), не Demucs. Для студийного качества — внешние сервисы (moises.ai и т.п.).

## Проверка

1. AI Lab → **ДОРОЖКИ** → **МИНУС** → файл со стерео вокалом → ▶ минус.
2. **ВОКАЛ** → тот же файл → ▶ вокал.
3. **ВСЕ 5** → бас / середина / высокие + вокал + минус.
4. ↗ экспорт WAV; на Android — звук в беззвучном режиме iOS.
