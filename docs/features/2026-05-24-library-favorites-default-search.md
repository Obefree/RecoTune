# База песен: избранное по умолчанию, поиск без «32 filler»

**Дата:** 2026-05-24  
**Зачем:** при открытии модала не показывать все ~32 встроенные песни; в поиске — только релевантные совпадения сверху, без подмешивания несовпавших builtin.

## Файлы

| Путь | Изменение |
|------|-----------|
| `src/screens/ChordsScreen.tsx` | `libFavOnly` по умолчанию `true`; `libResults` / пустой поиск / счётчик / empty state |

## Было → стало

| Было | Стало |
|------|--------|
| Пустой поиск → весь `librarySongs` (~32 builtin + свои) | Пустой поиск → только избранное (или весь каталог, если снять ⭐ Избранное) |
| `libSearchHits = librarySongs` при очистке поля | Пустые hits; список строится из favorites / search |
| Поиск: rank OK, но дефолтный список «забивал» builtin | Поиск: `searchProviders` + `searchSongsSmart`, только совпадения, сортировка по `libSearchRank` |
| Нет подсказки при пустом избранном | «В избранном пусто…» + поиск / снять фильтр |
| Счётчик «N из {весь каталог}» | «N избранных» / «N найдено» / «N из M» при полном каталоге |

## Поведение (кратко)

| Состояние | Список |
|-----------|--------|
| Поиск пуст, ⭐ Избранное вкл. (дефолт) | Только `favorites` |
| Поиск пуст, ⭐ выкл. | Весь локальный каталог |
| Есть текст в поиске | Весь каталог (metadata + builtin + user), порядок по rank |
| ⭐ при поиске | Не сужает выдачу — поиск глобальный |

## Проверка

1. Chords → Практика → База: без избранного — пустой список и подсказка.  
2. ⭐ у песни → она в списке без поиска.  
3. Поиск «кино» — совпадения сверху, без лишних builtin без match.  
4. Снять ⭐ Избранное — виден полный локальный каталог.
