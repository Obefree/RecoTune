# База песен: убрать «фантомное» предвыбор меню

**Дата:** 2026-05-24  
**Зачем:** после `libFavOnly` по умолчанию казалось, что «что-то странное предвыбрано»: два подсвеченных чипа, кракозябра на «ТАБЫ», модал при каждом входе на вкладку даже с уже выбранной песней.

## Файлы

|------|-----------|
| `src/screens/ChordsScreen.tsx` | авто-открытие базы; чипы; сортировка; подпись ТАБЫ |

## Было → стало

| Было | Стало |
|------|--------|
| При каждом фокусе вкладки Chords — `setShowLibrary(true)` | Модал только если **нет** `practiceSong`; при выбранной песне — закрыт |
| Два активных чипа: ⭐ Избранное + **А→Я** (оба `true` по умолчанию) | Один фильтр по умолчанию — ⭐ Избранное; сортировка А→Я **без** чипа |
| Чип «ТАБЫ» с mojibake `Ð¢ÐÐ'Ð«` | Нормальная подпись **ТАБЫ** |
| Снять «А→Я» — неочевидный порядок списка | Без поиска список всегда по алфавиту |

## Поведение (кратко)

1. **Первый вход / нет песни в практике** — модал «База песен», список избранного (или подсказка «В избранном пусто…»).
2. **Песня уже выбрана** — вкладка Chords открывается на практике, база **не** всплывает; открыть вручную (кнопка «База» / поиск).
3. **Фильтры** — подсвечены только включённые: ⭐ Избранное (дефолт), ТАБЫ (опционально).

## Проверка

1. Выбрать песню → уйти на другую вкладку → Chords: модала нет, практика на месте.  
2. Сбросить песню / первый запуск: модал базы, один оранжевый чип «Избранное».  
3. Чип «ТАБЫ» читается по-русски, без кракозябр.
