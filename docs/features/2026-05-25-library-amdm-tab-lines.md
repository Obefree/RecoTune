# База песен, AmDm-парсер, табулатура в практике

**Дата:** 2026-05-25  
**Зачем:** список не выглядит пустым; подгрузка AmDm без HTML-мусора; строки `e|--0--|` не рвутся по символам.

## Файлы

| Путь | Изменение |
|------|-----------|
| `tools/chord-fetch/amdmFetch.mjs` | Выбор лучшего `<pre>` (podbor), фильтр UI-строк |
| `tools/chord-fetch/test-endpoint.mjs` | Проверка: нет HTML в начале ChordPro (Creep) |
| `src/utils/chordLyricsNormalize.ts` | `isTablatureLine`, таб-строки без нормализации |
| `src/utils/songContent.ts` | `libraryListChordSnippet` для списка |
| `src/screens/ChordsScreen.tsx` | Прогрессия в строке; таб — горизонтальный monospace; каталог по умолчанию |

## Было → стало

| Было | Стало |
|------|--------|
| ⭐ Избранное по умолчанию → пустой список без звёзд | Каталог целиком; ⭐ опционально |
| Пустая строка аккордов у metadata / без `chords` | `Am C G` или `—` |
| `$('pre').first()` — иногда chrome сайта | `pickAmdmPreHtml` + отсев UI-строк |
| `e|--0--1--|` переносится по буквам | Одна строка, горизонтальный скролл, monospace |

## Проверка

1. `node tools/chord-fetch/test-endpoint.mjs` — Creep, без `<` в первой строке текста.  
2. База песен — у песен видна прогрессия; без избранного список не пустой.  
3. Практика с таб-строками — одна горизонтальная линия.
