# Тюнер: восстановление ряда струн внизу

## Зачем

Пропала нижняя панель с открытыми струнами (E2 A2 D3 …) — остались только стрелка/график и инфо-полоса. Пользователю нужна визуальная привязка к строю выбранного инструмента.

## Файлы

- `src/screens/TunerScreen.tsx` — блок `stringsCard` + подсветка ближайшей струны через `findNearestString`

## Было → стало

| Было | Стало |
|------|-------|
| После хроматического режима (2026-05-20) сетка струн удалена из ScrollView | Ряд пилюль под START/STOP: номер струны + нота строя |
| — | Подсветка только индикатор (±50¢ к открытой струне); **стрелка и центы остаются хроматическими** |
| `5b7d288` не трогал UI струн (только график/timeAxis) | Регрессия воспринималась после увеличения `mainCard` под график — струны нужно прокрутить вниз |

## Проверка

1. Вкладка **Тюнер** → внизу карточка с 6 (или 4/7) пилюлями по выбранному строю.
2. **START**, сыграть открытую струну — соответствующая пилюля зелёная; центы/стрелка как раньше (до полутона).
3. Сменить инструмент/строй в picker — ряд обновляется.
4. Режим **График** — струны всё ещё видны ниже (при необходимости прокрутить ScrollView).
