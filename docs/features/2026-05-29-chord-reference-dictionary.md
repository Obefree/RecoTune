# Справочник аккордов + расширение схем

**Зачем:** в практике не хватало схем (E7, A7sus4, dim/aug на укулеле); справочник был спрятан в модале «Инструмент» и показывал только базовые типы.

## Файлы

| Файл | Изменение |
|------|-----------|
| `src/data/chordShapes.ts` | +E7, sus4, dim, aug, A7sus4 (гитара + укулеле); `listChordShapeKeys` |
| `src/data/chordShapeResolve.ts` | **новый** — enharmonic + fallback (7sus4→sus4→7→маж) |
| `src/data/basicChordCatalog.ts` | `getFullChordReferenceCatalog` — все ключи таблицы по ладам |
| `src/screens/ChordsScreen.tsx` | кнопка «Справочник», полный список, резолв в `ChordDiagram` |

## Было → стало

| | Было | Стало |
|---|------|--------|
| Справочник | «Основные аккорды» только из модала инструмента | Кнопка **«Справочник»** в баре практики + тот же вход в ⚙ инструмента |
| Состав списка | maj / min / 7 / maj7 / m7 | **Все** записи из таблицы инструмента (sus, dim, aug, add9, …) |
| Песенный аккорд без схемы | `?` / «нет схемы» | Fallback на близкий тип; подпись `≈Asus4` если имя другое |
| Укулеле | Часть типов только на гитаре | dim/aug/sus4/A7sus4 и др. в `UKULELE` |

## Политика no-stubs

Без фейковых грифов: если в таблице и fallback нет — честное «нет схемы для Укулеле» (и т.п.).
