# Chords: ревизия парсера, поиска и выравнивания (AmDm / UG)

Дата: 2026-06-24

## Зачем

Раздел «Аккорды» работал ненадёжно: парсер «странно» разбирал табы (аккорды
сваливались в начало строки, текст съезжал, в выводе мусор `/div>`), поиск
находил не то (ложные совпадения, чужие исполнители), а реальные песни иногда не
находились. Нужна была честная и точная цепочка: поиск → выбор → таб → практика.

## Корневые причины (найдено по реальным страницам amdm.ru)

1. **Выравнивание терялось.** `amdmPreHtmlToChordProLines` склеивал все аккорды
   chord-row в начало следующей строки текста (`[C][G][Em]слово`) и схлопывал
   `\s+`, объединяя строки. Колонки (позиция аккорда над слогом) терялись.
2. **Мусор в выводе.** Старый regex `([^<]+)` пропускал обрывки тегов (`/div>`)
   мимо стрипа — они попадали в таб.
3. **Поиск брал «сайдбар».** Кандидаты собирались по **всей** странице поиска
   (regex по всем `/akkordi/` ссылкам = 62 ссылки, в основном блок «новые табы»).
   Реальные результаты amdm.ru лежат только в `table.items` (часто 3–7 строк) —
   отсюда ложные совпадения вроде `andriy_kravchenko/bili_nochi` для запроса «Кино».
4. **Каверы/пародии не понижались** в выдаче (`peredelannye_pesni_parodii`,
   «… by Цоя», караоке) — иногда подменяли оригинал.
5. **UG (ultimate-api) не проходил валидацию:** отдавал «голые» chord-rows без
   `[скобок]`, а валидатор требует `[chord]` → всегда `no_chords`.
6. **og:title** «Би-2 - Кукушка» бился по дефису внутри «Би-2» → артист «Би».

## Что сделано

### Сервер (`tools/chord-fetch/`)

- **Новый `chordLayout.mjs`** — общий конвертер «аккорды-над-текстом → inline
  `[chord]`». Хранит колонку каждого аккорда и вставляет маркер над нужным слогом
  (snap к слову), корректно делит секции (`[Куплет]:C G Em` → строка-заголовок
  `Куплет:` + chord-row, со сдвигом колонок), держит fret-позиции (`Dm(V)` → `Dm`),
  intro-аккорды без текста, пустые строки-разделители. Один модуль вместо дубля в
  AmDm и UG.
- **`amdmFetch.mjs`:**
  - парс `<pre>` → колоночный plain-текст (chord-div → `data-chord`, остальные
    теги срезаны полностью — нет `/div>`-мусора) → `plainChordSheetToChordPro`;
  - кандидаты только из `table.items` (cheerio), относительные и абсолютные href;
  - скоринг: бонус за совпадение исполнителя в тексте, штраф за
    каверы/пародии/караоке (путь + текст ссылки);
  - быстрее: фразы поиска накапливают кандидатов в общий map, открывается не более
    `MAX_TAB_ATTEMPTS` страниц (раньше — каждая фраза × до 8 страниц; ~60 с → <1–3 с);
  - `parseOgTitle` делит по дефису **с пробелами** (`Би-2 - Кукушка`).
- **`ugFetch.mjs`:** ultimate-api прогоняется через `plainChordSheetToChordPro`
  (выравнивание + проходит валидатор); удалён мёртвый `ugWikiContentToLines`.
- **`chordSearch.mjs`:** живой поиск тоже только по `table.items` + штраф каверов.
- **`dev-proxy-server.mjs`:** версия `2026-06-24-aligned-parser` (телефон видит,
  что прокси обновлён).

### Приложение (`src/`)

- Удалён мёртвый `projectChordsOntoLyrics` (+ приватные хелперы) из
  `utils/chordProgression.ts` — числился в аудите и запрещён правилом no-stubs.
- Выравнивание в практике уже корректно рендерится `ChordLyricsLine` по inline
  `[chord]`; правок рендера не потребовалось.

### Тесты

- `tools/chord-fetch/verify-chord-layout.mjs` + `npm run verify-chord-layout`
  (13 проверок: выравнивание, секции, fret-позиции, intro). `verify-chord-normalize`
  без регрессий.

## Поведение «было → стало»

| Запрос | Было | Стало |
|--------|------|-------|
| Кино — Звезда по имени Солнце | «другой исполнитель», ссылка-мусор | честное «не найдено» (на amdm только пародии) |
| Сплин — Выхода нет | `[C][G][Dsus2][Em]Сколько…`, строки `/div>` | `Куплет:` + `[C]Сколько лет прошло, [G]все о том…` |
| Би-2 — Кукушка | title «2 - Кукушка», artist «Би» | title «Кукушка», artist «Би-2», аккорды над слогами |
| поиск «Король и Шут Лесник» | сайдбар-мусор | оригинал #1 (60), пародия ниже (45) |
| UG (ultimate-api) | `no_chords` всегда | выровненный `[chord]` ChordPro |

## Ограничения (честно)

- AmDm/UG требуют ПК-прокси (`npm run chords:dev` / `npm start`) + Flask
  ultimate-api для UG (`:5000`). На телефоне без прокси — только pesni.ru fallback.
- UG часто блокируется Cloudflare с домашнего IP → AmDm остаётся основным.
- Каталог amdm.ru не содержит часть оригиналов (например, Цой/Кино) — для них
  честное «не найдено», а не подмена пародией.
