# Tuner: адаптивное сглаживание (1€) + диапазон строя + защита от октавных ошибок

**Дата:** 2026-06-24

## Зачем

Несмотря на серию правок (cd0574a, eaaf99f, e5b0e81, d48411d, b2d90cd), тюнер оставался
неточным, дёрганым и «не держал» ноту. Диагностика показала, что проблема **архитектурная**,
а не в значениях констант: на пути «детектор → стрелка» стояли **три конфликтующих
сглаживателя** (rate-limiter 140 ¢/с + EMA + пружина) поверх throttle 100 мс и кадра 55 мс.
Rate-limiter двигал стрелку постоянной скоростью (линейные «ступеньки» ~0.7 с на полный ход),
пружина пыталась их переизгибать → «ползёт, потом дёргается». Один фиксированный фильтр
физически не может быть одновременно стабильным на удержании и быстрым на реальной смене.

## Что диагностировано (не угадано)

| Симптом | Корень |
|---------|--------|
| Лаг + ступеньки стрелки | rate-limiter постоянной скорости + пружина + throttle, наложенные последовательно |
| Нет баланса плавность/задержка | одинаковое сглаживание и в покое, и при смене высоты |
| Прыжки ноты, октавные ошибки | YIN брал **глобальный** минимум CMNDF (может зацепить суб-гармонику на октаву ниже) |
| Бас не настраивается вообще | `minHz: 60` отсекал E1 (41 Гц), A1 (55), B0, D1 |
| Лишний джиттер кадра | детект в диапазоне 60–1400 Гц для любого инструмента — широкий поиск, тяжёлый и шумный |

## Что сделано

| Файл | Изменение |
|------|-----------|
| `src/utils/tunerDisplay.ts` | **1€-фильтр** (Casiez 2012) в полутоновом домене вместо rate-limiter+EMA+spring. Гистерезис ноты сохранён. Confidence-gate (CMNDF > 0.18 → держим, не гоняем). Октавный glitch (>200 ¢ за кадр) пропускается, фильтр не «отравляется» |
| `src/components/TunerEngine.tsx` | `detectPitch`: octave-guard — берём **самый ранний** локальный минимум CMNDF в пределах допуска от глобального (истинная основная, не суб-гармоника). `minHz`/`maxHz` приходят из выбранного строя. `frameMs` 55→45 |
| `src/screens/TunerScreen.tsx` | Передаёт `minHz`/`maxHz` строя в движок (меньше октавных ошибок и меньше вычислений) и `yinConfidence` в дисплей |
| `src/components/TunerNeedle.tsx` | Пружина снова отзывчивая (stiffness 68→120, damping 28→17): вход уже сглажен 1€, можно не бояться джиттера |
| `tools/verify-tuner-display.mjs` | Переписан под 1€: стабильное удержание, отслеживание +25 ¢ за ~330 мс, нет run-ahead, octave/confidence reject |

## Было → стало

| Область | Было | Стало |
|---------|------|--------|
| Сглаживание стрелки | rate-limit 140 ¢/с + EMA + spring | один адаптивный 1€ (minCutoff 0.6, beta 0.9) |
| Диапазон детекта | 60–1400 Гц всегда | по строю: гитара ~61–725, бас ~31–215 |
| Выбор тона YIN | глобальный min CMNDF | ранний локальный min в допуске (octave-guard) |
| Бас | не работал (minHz 60) | работает (minHz из строя, до 28 Гц) |
| Тихий вход | rms-gate 0.0035 | без изменений + confidence-gate вместо «чейза» шума |

## Проверка

```bash
cd RecoTune
npm run verify-tuner-display
npm run verify-pitch-chart
npm run verify-tuner-chart
```

На устройстве: Tuner → START → тихий щипок: SIG и стрелка появляются, держатся ровно;
смена струны/бенд отслеживается за ~0.2–0.4 с без октавных скачков; бас (E1/B0) — определяется.
