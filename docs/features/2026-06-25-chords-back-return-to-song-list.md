# Chords: «Назад» из песни → чистый возврат к списку

**Дата:** 2026-06-25 
**Файл кода:** `src/screens/ChordsScreen.tsx` (хэндлер `onHardwareBack`)

## Симптом (Alex)

В Практике открыта песня (аккорды/текст), жмём аппаратный **«Назад»** — экран **дёргается и переключается на что-то странное**, а не возвращается к списку песен.

## Корень проблемы

Лестница `onHardwareBack` для песни в Практике была трёхступенчатой и оставляла «битое» промежуточное состояние:

1. 1-е «Назад» (immersive, `tabBarHidden`): только показывало панель + возвращало таб-бар → одновременная перестройка раскладки (таб-бар `display none→flex`, `lyricsMinHeight` пересчёт) = **рывок**.
2. 2-е «Назад»: `clearPracticeSelection()` чистило песню/текст, **но не открывало модалку списка** (`showLibrary`). Получался **пустой экран Практики без песни и без списка** — «странный/неправильный» вид.

`showLibrary` ставится в `true` только в фокус-эффекте (при входе на таб без выбранной песни), а не при очистке выбора внутри экрана — поэтому возврат «повисал» на пустоте.

## Что сделано

«Назад» из выбранной песни теперь **детерминированно одним нажатием**:

| Было | Стало |
|------|-------|
| back → показать панель; back → очистить (пустой экран); back → сменить таб | back → сброс immersive + таб-бар + очистка + **открыть список песен** |

Ветка в `onHardwareBack` (когда `mode==='practice'` и есть `practiceSong`/`practiceInput`):

```
lyricsImmersiveRef.current = false;
setTabBarHidden(false);
clearPracticeSelection();
setShowLibrary(true);
return true;
```

- Поставлена **выше** ветки `tabBarHidden` (в immersive песня всегда выбрана, так что одна ветка покрывает оба случая; ветка `tabBarHidden` осталась как safety-fallback).
- Удалена ставшая мёртвой ветка «показать панель по back» — раскрыть панель из immersive по-прежнему можно тапом (`Pressable` в области текста).
- Из `deps` убраны больше не используемые `practiceLyrics`, `showPracticePanel`; добавлен `setShowLibrary`.

Возврат к списку — это slide-in модалки `showLibrary` (тот же экран, откуда выбрали песню), без пустого промежутка и без двойного reflow.

## Проверить на устройстве

1. Практика → выбрать песню с текстом (immersive, таб-бар скрыт) → **Назад** → сразу список песен, без рывка и пустого экрана.
2. Песня без текста (только прогрессия) → **Назад** → список песен.
3. Список песен открыт → **Назад** → список закрывается (без регресса).
4. Режимы identify/live — back-логика не затронута.
