# Chords: убран дубль-экран аккордов на результате НАЙТИ (старое лекало)

## Зачем

На странице результата вкладки **НАЙТИ** (`mode === 'identify'`, состояние «НАЙДЕНО») для песни из библиотеки с verified-аккордами рендерился **полноценный лист «аккорды над словами»** через `ChordLyricsLine` — визуально тот же экран аккордов, что и в Практике, но по **старому лекалу**: без zoom (A−/A+ 30–190%), без транспонирования (−½/+½/ориг.), без immersive, без автопрокрутки/BPM, без словаря аккордов и тапа по аккорду.

Это был артефакт/дубль: два разных рендера одних и тех же аккордов. Пользователь (Alex) видел «второй экран аккордов в старом виде».

Единственный правильный путь просмотра аккордов — **Практика** (`mode === 'practice'`), куда уже ведёт кнопка **«В практику с аккордами»** (`openIdentifyInPractice` → `pickSong(libraryMatch)` → `switchMode('practice')`).

## Что сделано

- Удалён инлайн-рендер chord-sheet на результате НАЙТИ. Вместо листа `ChordLyricsLine` для verified-библиотечного совпадения показывается короткая подсказка: «Текст с аккордами открывается в практике — нажмите „В практику с аккордами“ выше».
- Обычный текст (lyrics.ovh / не-verified) по-прежнему показывается как plain text — это честный превью текста, не таб.
- Удалён мёртвый стиль `resultChordedLyrics`.
- `ChordLyricsLine` остаётся единственным рендером аккордов — только в Практике.

## Файлы

- `src/screens/ChordsScreen.tsx` — блок результата НАЙТИ (секция «ТЕКСТ ПЕСНИ»), удаление стиля `resultChordedLyrics`.

## Было → стало

| | Было | Стало |
|---|------|-------|
| Результат НАЙТИ (verified из библиотеки) | Полный лист аккорды-над-словами (`ChordLyricsLine`), старый статичный вид | Подсказка → открыть в Практике |
| Рендеров аккордов в коде | 2 (Практика + результат НАЙТИ) | 1 (только Практика) |
| Просмотр аккордов | Два разных экрана | Единый — Практика (zoom/транспонирование/immersive/автоскролл) |
| Plain-текст (lyrics.ovh) | Plain text | Plain text (без изменений) |

## Проверка

1. НАЙТИ → найти песню, которая есть в библиотеке с аккордами → на результате нет второго «листа аккордов»; есть подсказка и кнопка «В практику с аккордами».
2. «В практику с аккордами» → открывается обычный экран Практики с полным набором контролов.
3. НАЙТИ песню без аккордов (только lyrics.ovh) → показывается обычный текст, как раньше.
