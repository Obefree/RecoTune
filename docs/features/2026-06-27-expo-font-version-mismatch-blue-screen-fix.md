# Фикс: синий/пустой экран на телефоне после долгой загрузки (expo-font 55 vs SDK 54)

## Симптом

На телефоне (Expo Go / dev-сборка) RecoTune после длительной загрузки («долгих раздумий») показывал **синий/пустой экран**. В Metro и при `expo export` бандл собирался **без ошибок**, `tsc` проходил — значит, это не ошибка сборки/импорта, а **рантайм-краш на устройстве** сразу после загрузки бандла.

## Причина (root cause)

`@expo/vector-icons` объявляет зависимость `"expo-font": ">=14.0.4"` (открытый диапазон, без верхней границы). При установке npm разрешал этот диапазон в **самую свежую опубликованную** версию и поднимал (hoisting) на верхний уровень `node_modules/expo-font@55.0.7`, тогда как Expo SDK 54 ожидает `expo-font@~14.x` (нативный модуль `ExpoFontLoader` в Expo Go SDK 54 — это 14.x).

В итоге было два `expo-font`:

| Где | Версия | Корректно для SDK 54 |
| --- | --- | --- |
| `node_modules/expo-font` (верхний, его берёт `@expo/vector-icons`) | **55.0.7** | ❌ |
| `node_modules/expo/node_modules/expo-font` | 14.0.11 | ✅ |

JS из `expo-font@55` вызывает нативный API шрифтов, который не совпадает с нативной частью SDK 54. `@expo/vector-icons` (иконки `Ionicons`) рендерятся в таб-баре **на первом кадре**, поэтому краш происходил сразу после загрузки бандла → синий/пустой экран. Бандлинг это не ловит (резолв путей валиден), `tsc` тоже.

Подтверждено `npx expo-doctor`: «Missing peer dependency: expo-font» + «duplicate native module dependencies… expo-font@55.0.7 / expo-font@14.0.11».

## Фикс

`npx expo install expo-font` — добавил прямую зависимость нужной под SDK 54 версии, npm схлопнул дубликат:

- `package.json` → `"expo-font": "~14.0.12"` (прямой dependency, фиксирует верхний уровень на 14.x, чтобы открытый диапазон `@expo/vector-icons` больше не утаскивал 55.x).
- Верхний `node_modules/expo-font` теперь `14.0.12`; вложенный дубликат удалён (дедуп).
- `app.config.js` **не трогали** — config-plugin `expo-font` нужен только для бандла кастомных шрифтовых файлов, а иконки грузятся в рантайме через `Font.loadAsync`. Плагин не добавляем.

## Было → стало

| | Было | Стало |
| --- | --- | --- |
| `expo-font` (верхний уровень) | 55.0.7 | 14.0.12 |
| Дубликаты `expo-font` | 2 | 1 |
| `npx expo-doctor` | 12/18 | 14/18 (font-проверки зелёные) |
| `expo export --platform android` | clean (но рантайм-краш) | clean |

## Как запускать сейчас

1. `npm install` (на всякий случай — лок уже починен).
2. `npm run start` (или `npm run start:offline` без локальных серверов).
3. На телефоне — перезапустить приложение из Expo Go (если экран всё ещё старый — очистить кэш Expo Go и пересканировать QR), бандл соберётся 1 раз ~20–30 c, дальше экран Tuner.

## Затронутые файлы

- `package.json` (+`expo-font` в dependencies)
- `package-lock.json` (дедуп expo-font → 14.0.12)
