# Мегафон: антифон (петля колонка → mic)

**Дата:** 2026-08-17 · **Файлы:** `TunerEngine.tsx` (monitor HTML), `micLiveMonitor.ts`

## Зачем

Звук с колонки (уже снятый с микрофона) не должен снова попадать в телефон и усиливаться по кругу.

Гейт на паузах этого **не** закрывает: пока говоришь, гейт открыт, и петля жива.

## Что рвёт петлю

| Средство | Роль |
|----------|------|
| Сдвиг частоты ~6 Гц на выходе | Эхо с колонки не складывается в тот же тон → нет бесконечного воя (классика PA) |
| WebRTC AEC | Вычитает известный выход из mic (лучше на динамике телефона, слабее на BT) |
| Гейт | В паузах выход mute, чтобы петля не крутилась без речи |
| Детектор воя | Узкий пик в спектре → краткий duck |

Тюнер не трогали.
