# Сохранение записей диктофона и студии наружу

**Дата:** 2026-08-17 · **Файлы:** `playbackUri.ts`, `RecorderScreen.tsx`, `StudioScreen.tsx`, `app.json`

## Зачем

Записи жили только в песочнице приложения. Uninstall стирал диктофон и студию.

## Было → стало

| Было | Стало |
|------|--------|
| Диктофон только внутри приложения | После Stop — копия в альбом **RecoTune** (Музыка). **SAVE ALL** копирует уже лежащие файлы туда же. Share остаётся |
| Студия EXPORT → только share sheet | **Merge all → WAV** сразу копируется в тот же альбом; share по желанию |
| Сессия Studio как проект | По-прежнему только в приложении. После uninstall остаётся **аудио микса**, не список дорожек |

Нужно разрешение на аудио/медиа. Файлы: `Музыка` / альбом RecoTune (имя может чуть отличаться на Android).
