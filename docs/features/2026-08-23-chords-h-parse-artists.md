# Chords: H/Hm7/5- в чипах + аккуратные исполнители

## Зачем

На практике `[H7]` и `Hm7/5-` оставались текстом. Каталог грузился повторно на каждый заход во вкладку; «Кино (Виктор Цой)» и похожие имена отрывали песни от исполнителя.

## Корень

Рендер искал только `\[[A-G]`. `Hm7/5-` не проходил токен (слэш только под бас `/C`). Имена с скобками не канонизировались.

## Стало

- Общая грамматика `chordToken.ts`: H, `m7/5-`, `7+`, `b5`, и цепочки `A7sus4` / `Dmadd9` / `Em11` / `D6sus2` (не один суффикс)
- Чипы и follow-mic видят H7 / Hm7/5-
- Исполнитель: `Кино (Виктор Цой)` → **Кино**
- Каталог не перечитывается на каждый focus; сеть-probe только в dev

`npm run verify-chord-normalize` · `npm run build-catalog`
