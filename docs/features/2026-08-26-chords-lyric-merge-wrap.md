# Chords: склейка аккордов с текстом + перенос строк без чипов

## Зачем

После парсинга куплет без аккордов «рвался»: строка аккордов (`[Am]          [E]`) не склеивалась с текстом, если аккордов меньше, чем слов. Практика рисовала чистый текст как колонки под пустым слотом аккорда — переносы ломались. Пиллы базы снова перехватывал список.

## Было → стало

| Было | Стало |
|------|--------|
| Merge только при 1:1 или «аккордов больше, чем слов»; `[Am]` не считался chord-row | Колонки (3+ пробела, чип на начало слова), иначе spread по словам |
| Строка без `[Chord]` — flex-колонки с пустым слотом | Обычный абзац `Text` на всю ширину |
| Пиллы Исполнители/Песни — `TouchableOpacity`, chrome без фона | `Pressable` + непрозрачная шапка над списком |
| Список исполнителей пересчитывался каждый рендер | `useMemo` |
