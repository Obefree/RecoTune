# Chords: меньше лагов в базе и в практике

## Зачем

Вкладка «Аккорды» сильно тормозила: список пересобирал и сортировал весь каталог, строки таба перерисовывались на каждый кадр микрофона.

## Файлы

- `src/screens/ChordsScreen.tsx`

## Было → стало

| Было | Стало |
|------|--------|
| Каждая строка таба парсилась заново на любой setState (mic, cents) | `React.memo` + разбор строки один раз |
| База: `localeCompare` по всему каталогу даже без поиска | Сортировка только выдачи поиска |
| `libListRows` новый массив на каждый рендер | `useMemo` |
| `resolveSongEntry` в каждой видимой строке списка | Бейдж из полей индекса |
| Справочник считался всегда | Только когда модалка открыта |
