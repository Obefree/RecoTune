# Expo SDK 57 — Expo Go снова запускается

Официальный клиент Expo Go поддерживает **только последний SDK**. RecoTune был на 54; Go обновился до **57** (changelog 2026-06-30: RN 0.86.3, React 19.2.3, `npx expo install expo@^57.0.0 --fix`). `expo-av` убран из Go с SDK 55; в 57 его нет в bundled native modules — аудио/видео: `expo-audio` + `expo-video`.

## Было → стало

| | Было (SDK 54) | Стало (SDK 57) |
|--|---------------|----------------|
| Expo | `~54.0.x` | `~57.0.17` (установлен 57.0.21) |
| RN / React | 0.81.5 / 19.1 | 0.86.3 / 19.2.3 |
| Аудио | `expo-av` + патч Android 14 | `expo-audio` / `expo-video`; патч `expo-av` удалён |
| Expo Go | gate ExponentAV / dev APK | QR в Go **57**; gate только если нет `ExpoAudio` |
| APK bats | skip prebuild, если есть `android/` | prebuild `--clean`, пока нет штампа SDK 57 |

## Файлы

- `package.json`, `RecoTune.bat`, `build-apk.bat`, `build-apk-release.bat`
- `app.json` (плагины audio/video), `app.config.js` (ProGuard Media3)
- `src/utils/audio.ts` — Sound/Recording поверх `createAudioPlayer` / `AudioRecorder` (Studio mix на refs, не hooks)
- экраны Tuner/Studio/Chords/Melody/Media/AI Lab, `VideoScreen` → `VideoView`
- `src/utils/playbackAudioMode.ts`, `recordingAudioMode.ts`, `qualitySettings.ts`, `studioAudioRouting.ts`

## Почему отдельный `audio.ts`

`expo-audio` не drop-in для `Audio.Sound.createAsync` / `new Audio.Recording()`. Одна обёртка вместо шести копий ms↔seconds в Studio mix.
