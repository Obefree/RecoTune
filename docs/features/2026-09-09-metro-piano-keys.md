# Метроном без наслоения + клавиатура Piano

## Зачем

Клик метронома шёл `setInterval` + `replayAsync`: JS лагал, удары наслаивались, выключение не гасило уже запущенные. Нужны играемые ноты: в меню инструмента Piano — две октавы клавиш с тембром, не синус-петля.

## Файлы

- `src/utils/audio.ts` — один looping WAV на удар (тик + тишина); `metroGen` гасит in-flight start; piano WAV
- `src/utils/noteUtils.ts` — инструмент Piano, C3–B4; `midiToHz`
- `src/screens/TunerScreen.tsx` — клавиатура при Piano

## Было → стало

| Было | Стало |
|------|--------|
| Пищащий синус, несколько кликов сразу, стоп не всегда | Короткий wood-тик, один луп, стоп сразу глушит |
| Только пиллы струн | Вкладка «Ноты»: клавиатура C3–B4 |
