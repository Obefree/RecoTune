# Пианино — детектор, метроном, удержание, 1 октава

## Зачем

На вкладке «Ноты» нужна проверка попал/мимо (как в тюнере), метроном, выбор тембра, стабильный звук при удержании и широкие клавиши для больших пальцев.

## Файлы

- `src/screens/PianoScreen.tsx` — детектор над клавиатурой, метроном, тембр, 1/2 окт, hold
- `src/utils/audio.ts` — `pianoSustainSamples` + `playReferenceTone({ loop, piano })`
- `App.tsx` — иконка пианино в таб-баре
- `src/i18n/strings.ts` — подписи тембра и октав

## Было → стало

| Было | Стало |
|------|--------|
| Только клавиши | Сверху: нота / центы / в строю, как в тюнере; цель = нажатая клавиша |
| Нет метронома на этой странице | Тот же `MetronomeBar`, что в тюнере |
| Один тембр, две октавы | Пианино / синус; **1 окт** (шире) или **2 окт** |
| Короткий удар, потом другой луп | Один тон с нажатия до отпускания |
| Луп щёлкал / хрипел динамик | Короткий точный период, без клипа |
| Тихий бас, двойной удар, задержка | Громче низкие; плееры греются заранее; нажатие не перерисовывает клавиатуру |
| Иконка `apps` | Стилизованное пианино внизу в табах |
