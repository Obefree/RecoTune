# Пианино — отдельная вкладка «Ноты»

## Зачем

Клавиатура стояла в меню инструментов тюнера — путалась со строем гитары. Нужна своя кнопка и крупные клавиши для игры нот.

## Файлы

- `src/screens/PianoScreen.tsx` — экран клавиатуры (две октавы, −8va/+8va). Новый файл: это отдельный экран, не правка тюнера.
- `App.tsx` — таб Keys после Tuner
- `src/screens/TunerScreen.tsx`, `src/utils/noteUtils.ts` — Piano убран из строя

## Было → стало

| Было | Стало |
|------|--------|
| Piano в списке Guitar/Bass | Вкладка **Ноты** в таб-баре |
| Узкая клавиатура в карточке струн | Крупные клавиши внизу экрана, имя ноты сверху |
