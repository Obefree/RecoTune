# Tuner: звук струн + метроном (практика / студия)

## Зачем

В тюнере пиллы строя только подсвечивались — сыграть эталон нельзя. Метронома в приложении не было (roadmap помечал его как готовый ошибочно). Нужен слышный клик в тюнере, практике аккордов и студии; в студии клик **не** пишется в файл дорожки.

## Файлы

- `src/utils/audio.ts` — эталон и клик через `expo-audio` WAV (WebView-клик молчал без жеста)
- `src/utils/metronomeClick.ts`, `src/components/MetronomeBar.tsx` (компактный ряд)
- `src/screens/TunerScreen.tsx`, `ChordsScreen.tsx`, `StudioScreen.tsx`, `MelodyScreen.tsx`
- `src/i18n/strings.ts`

## Было → стало

| Было | Стало |
|------|--------|
| Пиллы струн в тюнере немые | Тап — петля эталона на частоте струны; повторный тап стоп |
| BPM в практике только крутит текст | Кнопка клика рядом с BPM |
| Студия без метронома / отдельная карточка | Клик в шапке Studio, компактный; не в WAV дорожки |
| Melody PLAY без сетки | Метроном в одном ряду с PLAY |

`npm run verify-metronome`
