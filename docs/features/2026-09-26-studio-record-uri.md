# Studio: запись снова сохраняет дорожки

## Зачем

После SDK 57 обёртка `expo-audio` в `Audio.Recording` обнуляла нативный рекордер в `stopAndUnloadAsync()` раньше, чем экраны читали `getURI()`. Студия (и диктофон / практика аккордов) останавливала REC, но файл не копировался в сессию — список дорожек не рос.

## Файлы

- `src/utils/audio.ts` — URI кэшируется после prepare/start/stop; `getURI()` живёт после unload, как в expo-av.

## Было → стало

| Было | Стало |
|------|--------|
| `this.rec = null`, затем `getURI()` → всегда `null` | Сначала `stop()`, URI в `lastUri`, потом release |
| Stop без ошибки и без новой дорожки | Файл копируется в `studio/`, дорожка появляется в сессии |
