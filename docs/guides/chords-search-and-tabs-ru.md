# Аккорды: поиск, табы и «адекватная база»

## Две разные вещи в приложении

1. **Поиск в «База песен»** — быстрый каталог: избранное, ~32 песни с **готовым табом** (ChordPro в приложении), ~5000 строк **метаданных** (исполнитель + название с MusicBrainz, **без текста**).
2. **Практика** — показывает **только проверенный таб**: построчные `[Am]` над словами. Не подставляются «угаданные» тексты и не склеивается прогрессия в фейковый таб.

Бейджи в списке:

| Бейдж | Значение |
|--------|----------|
| **текст ✓** | Есть verified ChordPro — можно играть сразу |
| **прогрессия, не таб** | Только цепочка аккордов в шапке |
| **метаданные** | Название из каталога; таб нужно подгрузить |

## Как получить полный таб

1. На ПК в папке RecoTune: `npm run dev-proxy` (порт 8787).
2. Телефон и ПК в одной Wi‑Fi; в ⚙ **Источники** включено «Табы с AmDm», URL прокси подставится автоматически (или укажите вручную).
3. Выберите песню из поиска — при открытии практики пойдёт подгрузка: **«Ищем на AmDm…»** → **«Проверяем текст и аккорды…»**.

Без прокси поиск всё равно найдёт **название**, но полный таб с AmDm не скачается.

## Если ошибка

| Сообщение | Что делать |
|-----------|------------|
| Прокси / `dev-proxy` | Запустите прокси на ПК, проверьте URL в ⚙ |
| **Другой исполнитель** | На AmDm нет вашего варианта (часто кавер). Уточните название или импортируйте `.cho` / ChordPro |
| **Слишком короткий / без текста** | Не та страница или только прогрессия — поправьте исполнителя |
| **Не найдено на AmDm** | Песни может не быть на сайте — импорт файла или другая песня из builtin |

Проверка связи: ⚙ → **Проверить** (тест Radiohead — Creep).

## Что значит «адекватная база» сейчас

- **~32 builtin** — полные табы в сборке, offline.
- **~5000 metadata** — удобный поиск «кто поёт что»; это **не** 5000 табов.
- **AmDm по запросу** — один таб на песню через прокси, с проверкой и кэшем после успеха.
- **Мои песни** — импорт ChordPro, ручной ввод.

Цель: в поиске не врать про таб; в практике — только то, что реально распарсили и проверили.
